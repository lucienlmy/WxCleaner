# 产品定义 (Product Definition) - WxCleaner

## 产品愿景与目标
WxCleaner 是一款专为清理微信及各类本地文件夹中重复文件而设计的轻量、安全、高效的桌面端工具。通过智能的三级过滤与哈希对比算法，帮助用户快速释放磁盘空间，同时通过系统回收站机制保障数据安全，彻底解决微信多端同步与接收造成的大量冗余文件问题。

## 目标用户与使用场景
- **目标用户**: 微信重度用户、电脑磁盘空间紧张者、需要定期整理本地文件资产的桌面端用户。
- **典型场景**: 微信文件目录（WeChat Files）长期积累了大量同名或不同名但内容完全一致的文件；需要批量识别并安全清理重复项，保留一份有效副本。

## 核心功能与特性
1. **智能三级扫描**: 按照「文件大小初筛 -> 文件头部 1024B 哈希 -> 全量 SHA-256 哈希」层级推进，兼顾极速与 100% 准确性。
2. **可视化管理与预览**: 列表清晰呈现文件序号、路径、大小、修改时间与状态，支持右键直接在资源管理器中打开文件位置。
3. **智能策略与标记**: 默认按路径长度推荐保留原始文件并标记冗余副本，支持一键全选重复项及手动调整。
4. **安全防误删机制**: 删除操作采用 `send2trash` 移动至系统回收站，支持二次确认与并发清理进度弹窗、支持中途停止。
5. **现代化交互体验**: 基于 `ttkbootstrap` 打造，支持 DPI 缩放适配与中文字体自适应。

## 非功能性需求与约束
- **性能**: 扫描过程不阻塞主 UI 线程，利用多线程并发进行哈希计算与回收站移动。
- **安全性**: 绝不硬删除文件；提供友好的错误报告机制。
- **本地化与语言**: 对话、文档与界面全面使用中文。
